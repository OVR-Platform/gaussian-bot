# ADR

Architecture Decision Records. Each file is a numbered decision. Template:

```
# NNN. Title

- Status: proposed | accepted | superseded by NNN
- Date: YYYY-MM-DD

## Context
(Why is this decision needed? What forces are at play?)

## Decision
(What did we decide?)

## Consequences
(What follows? Pros/cons/risk.)
```

Accepted / superseded records should never be edited in place — supersede them
with a new ADR that links back.
